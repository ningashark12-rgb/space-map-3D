# space-map-3D
3D Space Map with A* pathfinding in C++ using OpenGL

## Project Overview

3d Space Map is a C++ application designed to visualize stars in three-Dimensional space.
The application allows users to select two stars and find the shortest path between them using the A* pathfinding algorithm.

The project demonstrates object-oriented programming (OOP), graph algorithm and 3D graphics using C++.

## Technologies Used

- C++ - Main programming Language.
- SFML - Handles windows creation, user input and events.
- OpenGL - Renders the 3D space environment.
- GLM - Provides mathematical operations for 3D graphics.
- CMake - Manages the project build process.
- Git and GitHub - Used for version control and team collaboration.
- STL - Provides containers and aldorithms for data management.

  ## Main Features

  - 3D visualization of stars in space.
  - Interractive camera movement and navigation.
  - Selection of starting and destination stars.
  - Shortest path calculation using A* algorithm.
  - Dispaly of calculated paths in 3D environment.
  - Loading star information from external data files.
  - Object-oriented design using inheritance and polymorphism.
